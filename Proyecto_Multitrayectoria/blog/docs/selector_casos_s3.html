Selector de condiciones del canal S3

Seleccione uno de los cuatro taps de eco usados por los flujogramas QPSK y BPSK. Este selector documenta el modelo determinista; no presenta mediciones de receptor.

Condición del tap retardado

Tap complejo c0 + 0j
Magnitud y fase del eco0 · fase indefinida
H(0) = 1 + c1 + 0j
H(Rs/2) = 1 − c1 + 0j

Modelo y parámetros

h[n] = δ[n] + c·δ[n−8]

H(f) = 1 + c·exp(−j2πfτ)

El camino directo es h[0] = 1. El eco usa D = 8 muestras, fs = 256 kS/s y τ = D/fs = 1/Rs = 31,25 µs, con Rs = 32 ksym/s. La respuesta discreta se repite cada fs/D = 32 kHz; los valores H(0) y H(Rs/2) muestran los extremos de un período.

El dB de las magnitudes se calcula como 20·log10(|H|). Las curvas son la respuesta analítica del canal, no una PSD ni resultados experimentales.
