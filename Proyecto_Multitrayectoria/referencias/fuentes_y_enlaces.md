# Fuentes y enlaces técnicos

Las referencias del blog y esta lista se mantienen sincronizadas para que el
repositorio tenga una fuente auditable de los fundamentos utilizados.

1. Grupo Tema 3, *Decisión Técnica Ciega — Proyecto Beta de Comunicaciones II*,
   ficha interna del curso, Universidad Industrial de Santander, 2026.
2. MathWorks, [Phase Modulation — QPSK](https://www.mathworks.com/help/comm/ug/phase-modulation.html),
   documentación de Communications Toolbox.
3. MathWorks, [Multipath Fading Channel in Simulink](https://www.mathworks.com/help/comm/ug/multipath-fading-channel-1.html),
   documentación de Communications Toolbox.
4. GNU Radio, [Delay](https://wiki.gnuradio.org/index.php/Delay), GNU Radio Wiki.
5. GNU Radio, [QT GUI Constellation Sink](https://wiki.gnuradio.org/index.php/QT_GUI_Constellation_Sink),
   GNU Radio Wiki.
6. GNU Radio, [QT GUI](https://wiki.gnuradio.org/index.php/QT_GUI),
   visualizadores de tiempo y frecuencia.
7. GNU Radio, [Root Raised Cosine Filter](https://wiki.gnuradio.org/index.php/Root_Raised_Cosine_Filter),
   GNU Radio Wiki.
8. MathWorks, [Filtering in Communication Systems](https://www.mathworks.com/help/comm/ug/filtering.html),
   documentación de Communications Toolbox.
9. MathWorks, [Sinks — Eye Diagram](https://www.mathworks.com/help/comm/ug/sinks.html),
   documentación de Communications Toolbox.
